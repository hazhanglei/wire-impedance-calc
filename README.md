## 💡 使用提示

### 参考阻抗值
- **Micro USB**: 30~40 mΩ
- **Type-C**: 20~25 mΩ
- 主机端/设备端输入时，建议取中间值（如Type-C取22mΩ）

### 计算公式
```
截面积 = (线径/2)² × 3.1415 × 芯数
直流阻抗 = 17.4 × 线长 / 截面积
沾锡后阻抗 = 直流阻抗 × 2 × 1.15
焊接主机端阻抗 = 主机端阻抗 × 1.15 + 沾锡后阻抗
焊接设备端阻抗 = 设备端阻抗 × 1.15 + 沾锡后阻抗
成品阻抗 = 沾锡后阻抗 + 主机端×1.15 + 设备端×1.15
管控阻抗 = 成品阻抗 × 1.05
```
