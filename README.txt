TH2512+ 智能直流低电阻测试仪 插拔测试程序
===========================================

【EXE文件位置】
E:\Hermes\00-配置档案总库\默认配置\04-成品导出目录\TH2512_DataLogger.exe

【运行环境】
- Windows 10/11
- 无需安装Python或任何依赖（已打包进EXE）

【功能说明】
- 跳变检测模式：自动识别探针插入/拔出
- 插入后：阻值下降至有效值，开始实时测试
- 拔出时：阻值跳回超量程，记录最后有效值
- 连续测试：可多次插拔，每次自动记录

【使用步骤】
1. USB连接仪器与电脑
2. 双击运行 TH2512_DataLogger.exe
3. 选择COM口 → 点击"连接串口"
4. 点击"▶ 开始测试"
5. 插入探针 → 显示"测试中..."和实时阻值
6. 拔出探针 → 自动记录一条结果
7. 重复5-6可进行多次测试
8. 点击"■ 停止测试" → 数据自动保存为Excel

【数据存储路径】
E:\Hermes\00-配置档案总库\默认配置\02-日常办公文件\Excel数据表\质量分析表格\
